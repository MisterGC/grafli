grafli at a glance

Draw a board with the keyboard, let your Claude Code session draw on it with you, at your desk or live in a meeting, and find every key by the mode it works in.

Two ways to work with your agent

The agent is a Claude Code session you already run. grafli never starts one: at your desk the session edits the file, in a meeting you connect it to the board.

At your desk

The session edits the file, the app shows it

grafliyour keys, saved as you go
→↓saves←↑redraws on change
board.grafliplain text, in git
→↓reads the notes←↑writes the board
Claude Codewith the grafli skill
T: split the cache in twoQ: why two queues?
  1. grafli skill install claude
    Once: the session learns to write boards that read well.
  2. Ask: draw the request path as a grafli board
    The session writes board.grafli and checks it with grafli render.
  3. grafli board.grafli
    The app opens it and redraws whenever the session changes the file.
  4. t click, type T: or Q:
    A task for the session, or a question it answers on the board.
  5. Ask: work the notes on the board
    It does the tasks and answers the questions beside them.
  6. git diff
    The board is text: review what changed, line by line.

In a meeting

grafli serve in a tab, your session as the agent

Browser tabspresent, edit, watch
→↓edits, : requests←↑drawings, live
grafli serveon your LAN or VPN
→↓requests←↑edits it
Claude Codeconnected via grafli agent
  1. claude mcp add -s user grafli -- grafli agent
    Once: Claude Code knows grafli's tools.
  2. grafli serve boards/ --host 192.168.1.20
    Three links per board: open present yourself, hand out edit or watch.
  3. claude --dangerously-load-development-channels server:grafli, then /mcp__grafli__connect
    Your session is the agent: every tab shows it in the bar, in purple.
  4. : plain language, or a on the selection
    Its edit lands and glows. More than 5 changes wait as a proposal: Enter takes it, x drops it.
  5. ⇧+U
    Takes back the agent's last edit; what the others changed stays.
  6. Ask: disconnect from grafli
    Leaving: the tabs show the agent as gone. Stop grafli serve and the board is gone from every tab; the files never left your machine.
